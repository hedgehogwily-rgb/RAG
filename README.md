День 5 — Генерация ответа на основе retrieved context

🎯 Цель дня
Собрать первый полноценный RAG pipeline: query → retrieval → context → LLM answer.

📋 Задачи
1. 🔗 Передавать retrieved chunks в prompt модели
2. 💬 Сгенерировать ответ только на основе найденного контекста
3. 📎 Добавить в ответ список источников или идентификаторов чанков
4. 🚫 Явно запретить модели придумывать факты вне контекста
5. 🧪 Проверить пайплайн на 5–10 вопросах
6. 📝 Сравнить ответ без retrieval и с retrieval

🎉 Критерии успеха
- ✅ Система проходит полный цикл RAG
- ✅ Ответ строится на retrieved context
- ✅ В ответе есть ссылки на источники или chunks
- ✅ По примерам видно, что retrieval делает ответ точнее и приземлённее
