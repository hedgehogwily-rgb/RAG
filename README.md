День 3 — Weaviate, embeddings и загрузка чанков в векторную БД

🎯 Цель дня
Поднять Weaviate, подготовить схему хранения и загрузить в него чанки с embeddings и метаданными.

📋 Задачи
1. 🗃️ Поднять Weaviate локально или через Docker
2. 🔌 Подключиться к Weaviate из Python через weaviate-client
3. 🧱 Создать collection / schema для чанков знаний
4. 🧬 Для каждого чанка получить embedding
5. 📦 Загрузить чанки, embeddings и метаданные в Weaviate
6. 🧪 Проверить, что объекты реально появились в базе
7. 📝 Добавить возможность повторной загрузки базы знаний без дублирования объектов

Какие метаданные стоит хранить
- document_id
- source_name
- chunk_id
- text

🎉 Критерии успеха
- ✅ Weaviate поднят и доступен из Python
- ✅ Создана структура хранения чанков
- ✅ Все чанки загружены в Weaviate
- ✅ Метаданные не потеряны
- ✅ База готова к retrieval по query
