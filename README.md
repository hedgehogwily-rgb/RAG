📝 День 2: rag_day02

День 2 — Chunking документов

🎯 Цель дня
Научиться разбивать документы на удобные чанки, пригодные для retrieval.

📋 Задачи
1. ✂️ Реализовать разбиение текста на чанки
2. 📏 Выбрать размер чанка и overlap
3. 🏷️ Для каждого чанка сохранить метаданные:
   - document_id
   - source_name
   - chunk_id
4. 🧪 Проверить, что длинные документы режутся корректно
5. 📝 Вывести несколько примеров чанков и их метаданные

Что важно понять
Слишком большие чанки ухудшают retrieval, слишком маленькие — теряют смысловой контекст.

🎉 Критерии успеха
- ✅ Документы режутся на чанки автоматически
- ✅ У чанков есть метаданные
- ✅ Есть понятный размер чанка и overlap
- ✅ На примерах видно, что чанки пригодны для поиска
