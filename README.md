День 4 — Retrieval через Weaviate

🎯 Цель дня
Научить систему получать вопрос пользователя, искать похожие чанки в Weaviate и возвращать наиболее релевантный контекст.

📋 Задачи
1. ❓ Реализовать обработку пользовательского query
2. 🧬 Получать embedding для запроса
3. 🔎 Выполнять semantic search в Weaviate
4. 📊 Возвращать top-k чанков вместе с:
   - score / distance
   - source_name
   - chunk_id
5. 🧪 Подготовить минимум 5 тестовых вопросов
6. 📝 Проверить руками, что retrieved chunks действительно релевантны вопросу

По желанию
Попробуйте сравнить обычный semantic retrieval и hybrid retrieval, если это удобно в вашей конфигурации Weaviate.

🎉 Критерии успеха
- ✅ Для запроса возвращаются top-k чанков из Weaviate
- ✅ Видны source и score найденных фрагментов
- ✅ Retrieval работает минимум на 5 вопросах
- ✅ Найденный контекст выглядит осмысленным, а не случайным
