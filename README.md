📝 День 1: rag_day01

День 1 — Загрузка документов и базовая подготовка базы знаний

🎯 Цель дня
Подготовить локальную базу знаний и научиться загружать документы в программу для дальнейшей обработки.

📋 Задачи
1. 📁 Создать папку knowledge_base/
2. 📄 Подготовить минимум 5–10 текстовых документов
3. 📥 Реализовать загрузку документов из файлов
4. 🧹 Добавить базовую очистку текста:
   - убрать лишние пробелы
   - убрать пустые строки
   - нормализовать формат
5. 🧪 Вывести в консоль список загруженных документов и их длину
6. 📝 Подготовить структуру проекта под будущий RAG pipeline

🎉 Критерии успеха
- ✅ Есть папка с базой знаний
- ✅ Программа читает минимум 5 документов
- ✅ Документы загружаются и очищаются
- ✅ Видно, что система готова к следующему шагу — chunking
