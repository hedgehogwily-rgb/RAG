День 6 — Качество retrieval и защита от галлюцинаций

🎯 Цель дня
Сделать RAG-систему более надёжной: оценивать качество retrieval и корректно обрабатывать случаи слабого контекста.

📋 Задачи
1. 📏 Добавить порог релевантности или heuristic для слабого retrieval
2. ⚠️ Реализовать поведение, когда good context не найден:
   - вернуть честное сообщение
   - не выдумывать ответ
3. 🧪 Подготовить вопросы:
   - на которые база знаний отвечает хорошо
   - на которые база знаний не должна отвечать
4. 📊 Оценить retrieval qualitatively:
   - насколько релевантны top-k chunks
   - есть ли лишний шум
5. 📝 Зафиксировать, какие настройки chunking/retrieval работают лучше

🎉 Критерии успеха
- ✅ Система умеет распознавать слабый контекст
- ✅ При плохом retrieval не выдаёт уверенную галлюцинацию
- ✅ Есть набор хороших и плохих тестовых вопросов
- ✅ Есть базовое понимание качества retrieval
